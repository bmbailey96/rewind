Connect PlayStation

One server setting starts hourly checks. Rewind keeps your imported shelf while Sony is unavailable.

  1. Open PlayStation in your own browser and sign in.
  2. In that same browser, open Sony’s session-token page. Copy only the 64-character value after npsso. If Sony reports an error, confirm you are signed in using that browser.
  3. Open your Rewind site in Netlify. Go to Project configuration → Environment variables. Add a secret variable named PSN_NPSSO, paste the value, and use Production. If your plan offers scope controls, choose Functions; otherwise the default all-scopes setting works.
  4. Redeploy Rewind so its functions receive the new setting. Return to Games and open PS5 sync status. The first check exchanges the session token and retrieves your history.
This is an account credential. Put it only in Netlify’s secret setting. Never put it in chat, GitHub, a screenshot, or the browser’s saved data. The site publishes game-history fields like its existing imported shelf; Sony credentials stay server-side.

Checks run hourly. The timestamp means Sony was checked successfully, not that Sony has already recorded your last session. If authorization expires, repeat these steps with a fresh value. Rewind stores rotated refresh tokens automatically.
